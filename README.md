 Laundry Management Website
This is a simple laundry service website built using HTML and CSS.  
It was created as a beginner-level web development project and deployed using GitHub Pages.

 Live Demo
https://theinternational.github.io/laundryproject

Project Features
- Simple and clean UI design
- Laundry service information layout
- Pricing / service sections
- Responsive basic structure

 Tech Stack
- HTML
- CSS
- GitHub Pages (for deployment)

This project was created to practice frontend development skills and understand how to deploy websites using GitHub.
